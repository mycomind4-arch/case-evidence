## Rules

- Never invent authors, dates, titles, quotations, page numbers, or source IDs.
- Keep publication date, event date, and access date distinct.
- A search result or abstract may support a limited summary but is not a substitute for reviewing the full paper's methods.
- Multiple sources that repeat one press release or dataset are not independent corroboration.
- If a source is inaccessible, label the evidence limit; do not silently rely on a summary as if full text was read.
