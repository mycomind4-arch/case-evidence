# Case Evidence — Shared Case Infrastructure

Case Evidence is shared infrastructure, not a consumer vertical.

It is the reusable foundation for document, evidence, provenance, timeline, and findings capabilities used by multiple master verticals.

Core primitives:
- document ingestion and extraction
- page/source provenance
- evidence records and relationships
- timeline/event reconstruction
- deadline primitives
- contradiction/gap detection
- human review state
- auditable findings

A consumer-facing workflow should normally live in the relevant master vertical repository and consume these capabilities rather than become another standalone Case Evidence product.
